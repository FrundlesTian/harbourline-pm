\chapter*{Abstract}
\rhead{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
This report evaluates the Harbourline AI project management system on the latest code. The harness \code{eval/run_eval.py} runs 34 test cases, T01--T34, each in a throw-away database against a mock project board, and computes five measures: gap recall, invention rate, re-run stability, Critic catch rate, and cost and time per full run. Both modes were run on 14 November 2026. In the deterministic baseline mode all 34 cases pass: gap recall is 91\%, 20 of 22 gold brief gaps; the invention rate is 0.0\%, 0 of 75 sampled claims; re-runs are identical with no duplicates; the Critic stops all 21 planted faults; and a full run takes 0.055\,s at no cost. In LLM mode, with DeepSeek, all 34 cases also pass: gap recall is 82\%, 18 of 22; the invention rate is 0.0\%, 0 of 92; the catch rate is 100\%; and a full run takes 92.5\,s, 79,812 tokens and US\$0.026. LLM outputs are not identical across fresh databases, but re-runs on the same database are, because responses are cached. Gap recall in LLM mode varies between runs, from 77\% to 82\%. The first LLM-mode runs exposed real defects, among them untraceable figures in generated risks, a missing conflict in the change analysis and a memory question wrongly answered NOT FOUND; these were fixed, and six checks that pinned baseline IDs were rewritten to test behaviour. The report closes with the limitations of the evaluation and the commands to reproduce it.
