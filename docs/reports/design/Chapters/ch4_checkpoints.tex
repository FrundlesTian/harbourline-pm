\chapter{Human checkpoint map}
\label{ch:checkpoints}

Checkpoints are defined in \code{app/audit.py:16-31}. The server records every approval under the selected session account, never a typed name, see \code{server.py:118-143}, and checks that account's role first in \code{app/auth.py:184-202}. Approvals go to the \code{approvals} table with approver, role, account, decision, comment and timestamp; the table is defined in \code{app/db.py:58-60} with migrations at \code{:95-98}. Each approval is mirrored in \code{audit_log}. \textbf{The account is chosen without a password}, so an approval shows which account approved, not which person; this is limitation L7 in Section~\ref{sec:limitations}. The start-screen \textbf{Reset demo} deletes the \code{approvals} table together with the other demo data; the mirrored rows in \code{audit_log} remain, as Chapter~\ref{ch:governance} explains.

Table~\ref{tab:checkpoints} lists the seven checkpoints, what each is bound to, and what happens if it is rejected or skipped. Keeping accountable decisions with named roles at defined points follows the governance practice in the PMBOK Guide \parencite{pmi2021pmbok7}.

\section{Not automated, by design}

\begin{itemize}[leftmargin=*,itemsep=2pt]
  \item \textbf{Moving items to Done, closing, resolving or deleting.} The brief makes these human acts in L247--L248. \code{Guarded} blocks them and logs \code{BLOCKED}, see \code{app/pmtool.py:378-390}; the forbidden fields are \code{status}, \code{resolution} and \code{resolutiondate}, listed in \code{app/pmtool.py:29}. Read-back reports items a human moved to Done, see \code{app/pmtool.py:586}.
  \item \textbf{Sponsor decisions}, such as closure priority in \code{SA-Q3}, contingency status in \code{EDC-1.2} or rooftop deferral in \code{EDC-6.3}. These appear as decisions with who and when, or as NOT FOUND, never as choices made by the agent, see \code{app/change.py:188-190}.
  \item \textbf{Report release at HC5 and risk re-scoring at HC6.} Agents propose; a person accepts, because the reports go to external bodies and scores drive the top-five list.
\end{itemize}
