\chapter{Agent cards}
\label{ch:agents}

Role and Context are fixed in \code{app/agents.py:9-91}; Appendix~\ref{app:prompts} gives the full text. \textbf{Model for every LLM call:} Gemini \code{gemini-2.5-flash} by default, set by the team in \code{.env} and read in \code{app/config.py:33}, with DeepSeek \code{deepseek-chat} as backup, see \code{app/config.py:42}; temperature 0.0, see \code{app/llm.py:66}. The Gemini path is tested only against a local stub; every LLM run the team made used DeepSeek, whose use the course instructor has accepted according to a team statement of 14 Nov 2026.

Tables~\ref{tab:card-planning}--\ref{tab:card-governance} give one card per agent module and one for the governance layer.

\textbf{Failure behaviour} & A STOPPED report is stored with its findings; HC5 release is refused, \code{app/reporting.py:291-298} \\
