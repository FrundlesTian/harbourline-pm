\addcontentsline{toc}{chapter}{Abstract}

This document describes the design of an AI-driven project management system for the Harbourline Community Hub Refurbishment, as built in the latest code. Six agent modules and a governance layer plan, track and report the refurbishment behind one local web user interface. The modules are Planning, Tool Integration, Memory \& Retrieval, Risk \& What-if, Reporting with its Critic, and Change. The system writes the approved plan into Jira Cloud or into a local mock board that implements the same contract. The core design principle is that \emph{the LLM drafts and deterministic code decides}: report numbers and dates come from verified facts, the LLM drafts structured content that must cite its sources, validators and a Critic check every draft, and a curated baseline is used when no model is configured or validation fails. Gemini is configured first and DeepSeek as backup. Seven human checkpoints, HC1 to HC7, sit between agent output and anything a stakeholder or the PM tool sees; four of them gate code paths, while HC1, HC4 and HC7 only record. The document covers the architecture, the agent cards, the checkpoint map, the data contract with the PM tool, change handling, governance and free-tier compliance, and the design trade-offs. It also states the known limitations, among them the passwordless demo identities and the project-wide Reset demo added on 11 Nov 2026, which the team has accepted, and the evidence that is kept outside the repository.
