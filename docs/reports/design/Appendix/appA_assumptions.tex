\chapter{Assumption register}
\label{app:assumptions}

\textbf{Seeding.} There is no standalone assumption file. The register is the Sponsor Question table:

\begin{itemize}[leftmargin=*,itemsep=2pt]
  \item Every question not answered by a source gets \texttt{ASSUMPTION A-nn: until the sponsor answers, plan treats this as unresolved\ldots} see \code{app/planning.py:513}.
  \item Approved HC6 actions append event notes, for example ``(CE-01)'', see \code{app/change.py:420-427}.
  \item The rows below are the \textbf{baseline} register GQ01--GQ20 from \code{app/planning.py:45-181}. In LLM mode the IDs and wording are regenerated on each fresh database; the live register is on the Planning page.
  \item Rows marked \textbf{added} cover G01--G14 items that the baseline register does not hold as a question.
\end{itemize}

Owners are role accounts; owners and revisit triggers were adopted by the team lead.
