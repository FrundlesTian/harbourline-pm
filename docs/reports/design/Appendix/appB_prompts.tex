\chapter{Agent prompts: Role and Context as stored}
\label{app:prompts}

The source is \code{app/agents.py}. No tokens appear in any prompt.

\textbf{Shared grounding text}, in \code{app/agents.py:4-7}: ``You may ONLY use the SOURCES given in the user message. Never use outside knowledge. If the sources do not contain the answer, say exactly NOT FOUND. Every claim must carry a citation in square brackets using the source id, e.g.\ [EDC-5.1]. When sources conflict, say so and cite both.''

\textbf{Generation grounding}, in \code{app/gen.py:73-76}: ``Use ONLY the SOURCES given. Never use outside knowledge or invent names, dates, amounts or owners. Every source id you output must be one of the ids shown in square brackets. If the sources do not state something, write NOT FOUND [\ldots] instead of guessing. Where sources disagree, say so and cite both. Return a single JSON object only.''
