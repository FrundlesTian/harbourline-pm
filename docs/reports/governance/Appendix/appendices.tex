\chapter{Reproduction commands}
\label{app:repro}

Both evidence sets are regenerated on a throw-away database against the mock board; the reset check also blanks the Jira credentials.

\begin{lstlisting}[language=bash,numbers=none]
# Demonstration run: audit_log.csv, agent_writes.csv, approvals.csv,
# bias_check.json, change_impact_CE-01.md, summary.json
python3 scripts/governance_demo.py

# Reset check: reset_check.json, mock board, Jira credentials blanked
python3 scripts/reset_check.py
\end{lstlisting}

The team's real records are exported with the Governance export in the UI.
