The writer's brief says the system runs Gemini via Google AI Studio, a Streamlit UI and an SQLite + JSONL audit log. **The repository contradicts all three.** Correct line:

> Python 3 standard library only: a `ThreadingHTTPServer` (`server.py`), a vanilla HTML/JS front end (`static/`), and SQLite (`app/db.py`). **Note for the design document (honesty point).** The content of the plan is hand-authored, version-controlled data in code that the agents assemble, check and store; it is not generated from the brief at run time. This covers scope lines, the 20 Sponsor Questions, 74 WBS rows, 18 milestones, 23 risk rows, report line templates and change-event analysis (`planning.py:12-202`, `risk.py:14-99`, `reporting.py:64-122`, `change.py:58-116`). What the code computes at run time:
- 12 conflict detectors, partly computed from facts
- the traceability filter
- seed-register QA
- the what-if arithmetic
- tag-based staleness
- all Critic checks
- the bias statistics

The LLM is optional and only adds gaps, an answer, a summary or a narrative, each of which is rejected unless its citations and numbers trace. §1 and §8 must say this plainly; the panel will ask.
